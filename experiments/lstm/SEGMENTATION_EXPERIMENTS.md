# Сегментация дефектов: журнал экспериментов

Цель: сегментация дефектов на ИК-термограммах, метрика **test IoU**, таргет **0.75–0.8+**.
Данные: kaggle `irt-pvc-depth` (38 видео, мелкие 2×2 мм дефекты) и tpu (18 видео,
крупные блоки), через новый data-слой `datasets/datasets_list/` (`TermoDataset`).
Оценка — **3-fold** по видео (test/val/train), TTA + подбор порога по val.

Финальный воспроизводимый прогон — `notebooks/seg_final_kaggle_tpu.ipynb`
(только последняя, лучшая итерация). Ниже — весь путь.

## Вход (признаки)

Постепенно обогащался; итоговый — **14 каналов**, поканальный z-score, 256×256:

| группа | каналов | что |
|---|--:|---|
| TSR-p5 | 6 | коэф. полинома 5° по `log(t)`/`log(ΔT)` (термосигнал-реконструкция) |
| PCA/EOF | 3 | спектральные EOF (PCA видеоряда) |
| PPT | 3 | фаза rFFT по времени, бины 1–3 (устойчива к неравномерному нагреву) |
| d2 | 2 | 2-я производная TSR-полинома `p''(u)` в двух log-временах (подчёркивает края) |

## Итерации (по нарастанию)

| # | что добавлено | test IoU (3-fold) | заметки |
|---|---|--:|---|
| база | 128×128, TSR+PCA (9ch), Adam 40эп, BCE+Dice | ~0.58 | full-frame U-Net |
| — | 256×256 + 14ch (PPT+d2) + cosine + early-stop | ~0.66 (single) | +резкость мелких дефектов |
| **1** | Attention U-Net + Focal-Tversky | 0.616 | приём НЕ помог (даже хуже) |
| **2** | + deep supervision + strong aug + TTA + thr-tuning | 0.653 | плато |
| **3** | + ансамбль (3 сида) | 0.654 | ансамбль почти ничего |
| **диагноз** | train≈val≈test (недообучение), σ по фолдам ±0.05 | 0.57±0.05 | узкое место = данные/разметка, не модель |
| **4** | **ImageNet-претрейн энкодер (resnet34, in_chans=14)** + аугментации из `datasets/` | **0.66** (σ ±0.010) | **скачок стабильности** (σ ×5 меньше) |
| **5a** | + boundary-loss (Kervadec) | 0.648 | НЕ помог (размыт сам сигнал, не край) |
| **5b** | EfficientNet-b0 бэкбон | **0.671 ± 0.020** | небольшой прирост, стабильнее |
| **6** | **+ tpu-домен (kaggle+tpu, 56 видео)** | all **0.68±0.07**, **tpu 0.72 (до 0.83)**, kaggle 0.66, лучший фолд **0.78** | цель взята на tpu и лучших сплитах |

## Что сработало / не сработало

**Сработало:**
- **Обогащение входа** (PPT-фаза, 2-я производная TSR): 0.58 → 0.66.
- **256×256** вместо 128 (мелкие дефекты).
- **ImageNet-претрейн энкодера** — сильнейший рычаг: лечит недообучение на 24
  видео, разброс упал в 5× (±0.05 → ±0.01).
- **EfficientNet** > resnet34 (небольшой стабильный прирост).
- **tpu-данные**: на tpu IoU 0.72 (до 0.83), лучший общий фолд 0.78.
- TTA + подбор порога по val — стабильно +2–4 пункта.

**Не сработало (плато 0.65):**
- Attention-gate, deep supervision, ансамбль, boundary-loss — почти не двигают IoU.
- Причина (по диагностике): **недообучение на малых данных** + **потолок разметки**
  — диффузный тепловой след крупнее резкого квадрата GT, что ограничивает
  граничный IoU (при этом Dice заметно выше).

## Итог по цели 0.75–0.8

- **Достигнута на tpu** (крупные дефекты): среднее 0.72, до 0.83.
- **Достигнута на лучших общих сплитах** (0.78).
- **kaggle-подмножество** (мелкие 2×2 мм) остаётся ~0.66 по IoU — принципиально
  труднее; по **Dice** там ~0.81. Дальнейший рост требует не тюнинга модели, а
  смены постановки для kaggle: **таргет «центр+размер»** дефекта либо **дилатация
  GT** под тепловой след, либо оценка по Dice.

## Стек / воспроизведение

- Модель: `timm` EfficientNet-b0 (ImageNet, `in_chans=14`, `features_only`) + U-Net-декодер (GroupNorm).
- Лосс: `0.5·BCE + Focal-Tversky`; Adam (enc 1e-4 / dec 1e-3) + CosineAnnealingLR + early-stop по val-IoU.
- Данные: `datasets/datasets_list/{dataset_kaggle,dataset_tpu}` (mat_key kaggle=`imageArray`, tpu=`data`); аугментации `datasets/aug.py` (HFlip/VFlip/Transpose/Rot90).
- Кэш признаков: `/tmp/seg14_cache.npz` (kaggle), `/tmp/seg14_tpu.npz` (tpu).
- Финальный блокнот: `notebooks/seg_final_kaggle_tpu.ipynb`.
