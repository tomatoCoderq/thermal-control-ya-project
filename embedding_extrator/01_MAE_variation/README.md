# MAE feature extraction — методы и эксперименты

Self-supervised претрейн video-MAE на ИК-термограммах (Kaggle `ziangwei/irt-pvc-depth`) и выгрузка
эмбеддингов для последующего дообучения под сегментацию/оценку глубины дефекта.

## Данные и предобработка
- Вход — сырые `.mat`-видео (`imageArray`) + маски дефектов (`manual_mask`/`automated_mask`).
- **TSR-денойзинг**: для каждого пикселя фитится полином 5-й степени по `ln(t)`/`ln(ΔT)`
  (Shepard 1997) + лёгкий гауссов блюр по кадру — убирает шум по времени и пространству.
- **Перцентильная нормализация по файлу** (1/99), а не min-max по каждому клипу — иначе клипы
  без выраженного сигнала растягивали в основном шум сенсора.
- **PCT (SVD)** используется только для диагностики "когда виден дефект" — на реальных данных
  сбивается тепловой вспышкой в начале записи, для автоматики не годится.
- Частичное чтение `.mat` с диска (только нужный диапазон кадров) — для скорости.

## Нарезка клипов
- Клипы (`clip_len=16` кадров) строятся вокруг реальных пиков контраста дефекта
  (`_file_peak_frames`, метод "дефект минус фон"), а не сплошной сеткой по всему видео.
- Взвешенный семплинг: клипы у пика контраста получают вес ×3 при попадании в батч.
- Маска используется не как таргет, а как **вес маскирования** — дефектные токены прячутся от
  энкодера чаще, с учётом и пространства, и времени (сильнее у пика контраста).
- Аугментация (только train): сдвиг кадра + обмен соседних блоков.

## Модель
- Video-MAE: кадр целиком (без ручной нарезки на независимые патчи), токенизация
  `tubelet_size(2) × patch_size(16) × patch_size(16)`.
- `mask_ratio=0.75`, encoder_depth=6, decoder_depth=2, embed_dim=256, num_heads=8.
- Задача претрейна — реконструкция замаскированных тюбов по видимым.

## Обучение и выгрузка фич
- Обучение — `train_mae` (batch_size=8, lr=1.5e-4, epochs=50).
- После претрейна — `dump_features`: энкодер прогоняется по клипам БЕЗ маскирования, эмбеддинги
  сохраняются по одному вектору на пространственно-временной токен (без агрегации), чтобы не
  терять информацию для следующего этапа.
