# Fourier phase classification

Этот эксперимент повторяет структуру ветки `polynom-classification`, но вместо
коэффициентов полинома пятой степени использует фазограммы преобразования Фурье.
Исходные `.mat`, маски, кропы, split по видео, классы глубины, CNN и метрики
остаются теми же.

Модель по умолчанию — `convnext_nano`, loss — `label_smooth`, 50 эпох: эти
параметры сохранены из ветки `polynom-classification`, чтобы сравнение способов
обработки было корректным.

## Что является входом модели

Для каждого пикселя строится временной температурный сигнал `T[y, x, t]` и
вычисляется `rFFT` по оси времени. Нулевая (DC) компонента пропускается. По
умолчанию сохраняются фазы первых восьми ненулевых частотных бинов, поэтому
кэш одного видео имеет форму `8 x H x W`.

При `Fs=10 Hz` и 1810 кадрах это частоты примерно от 0.00552 до 0.04420 Hz.
Точные значения записываются рядом с каждым `.npy` в одноимённый `.json`.

## Структура данных

В локальном клоне конфигурация использует датасет из родительской рабочей
папки, поэтому многогигабайтные `.mat` не копируются внутрь Git-репозитория:

```text
../data/R_002.mat
../data/Z_002.mat
...
../labels/automated_mask/R_002.png
../labels/automated_mask/Z_002.png
...
```

Пути и параметры FFT настраиваются в `config.yaml`.

## Запуск

Из корня клонированного репозитория:

```powershell
..\venv\Scripts\python.exe -m pip install -r fourier-exps/requirements.txt
..\venv\Scripts\python.exe fourier-exps/main.py --precompute-only
..\venv\Scripts\python.exe fourier-exps/main.py
```

Быстрая проверка на одном видео:

```powershell
..\venv\Scripts\python.exe fourier-exps/main.py --precompute-only --max-videos 1
```

Признаки сохраняются в `fourier_features/`, результаты обучения — в
`fourier_runs/<timestamp>_<tag>/`. Кэш автоматически перестраивается при
изменении параметров Fourier или исходного файла.

## Настройки Fourier

- `first_bin: 1` — пропуск постоянной составляющей.
- `n_frequencies: 8` — число низкочастотных фазограмм.
- `phase_encoding: raw` — фаза в диапазоне `[-pi, pi]`, как в статье.
- `phase_encoding: sin_cos` — альтернативное кодирование без разрыва на `pi`.
- `window: none` и `detrend: none` — вариант, наиболее близкий к описанию статьи.
- `start_at_peak: false` — FFT всей последовательности, а не только охлаждения.
- `row_chunk: 32` — обработка блоками строк, чтобы не создавать огромный FFT
  сразу для массива `256 x 320 x 1810`.
