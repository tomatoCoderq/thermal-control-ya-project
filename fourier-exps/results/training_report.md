# Отчёт об обучении Fourier-классификатора

Дата запуска: 16 августа 2026 г.

## Итог

Модель `convnext_nano` обучена на фазограммах восьми первых ненулевых
частотных компонент. Лучший checkpoint выбран по `macro-F1` на 34-й эпохе.

| Метрика | Значение |
|---|---:|
| Accuracy | 0.976608 |
| Balanced accuracy | 0.961806 |

| Weighted-F1 | 0.976300 |
| Ordinal MAE, классов | 0.070175 |
| Quadratic weighted kappa | 0.949954 |
| Правильных прогнозов | 167 из 171 |

## Данные и разбиение

- Всего термографических видео: 38.
- Обучающих видео: 28; отложенных тестовых видео: 10.
- Всего кропов: 680; train: 509; test: 171.
- Размер входного кропа: `8 x 48 x 48`.
- Разбиение сделано по видео с `seed=67`; кропы одного видео не попадают
  одновременно в train и test.
- Test-видео: `R_002`, `R_012`, `R_020`, `Z_004`, `Z_005`, `Z_011`,
  `Z_012`, `Z_017`, `Z_018`, `Z_020`.

## Fourier-признаки

- FFT вычислялась по временной оси каждого пикселя полной записи.
- Частота дискретизации: 10 Гц; кадров в записи: 1810.
- DC-компонента исключена.
- Использованы бины 1-8: 0.00552, 0.01105, 0.01657, 0.02210, 0.02762,
  0.03315, 0.03867 и 0.04420 Гц.
- Входные каналы — фаза в диапазоне `[-pi, pi]`.
- Оконная функция и detrending не применялись, чтобы соответствовать
  описанному в статье варианту Fourier phasegrams.
